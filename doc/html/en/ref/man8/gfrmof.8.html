Name

gfrmof — remove unconnected open descriptors that remain in gfmd

Synopsis

gfrmof [-P path] [-d file-descriptor] [-h file-system-node] [-p global-PID]

DESCRIPTION

Removes unnecessary file descriptors that remain unconnected.

gfmd keeps file open-states with the gfsd. Although gfsd reconnects to gfmd in after gfmd failover, in case gfsd is restarted, or a filesystem node crashes, etc, this file open-state may remain. At this time, gfmd periodically outputs the following warning log at the time interval specified by the directive unconnected_gfsd_watch_interval,

3 write-opened descriptors remain to be unconnected in gfsd, please check them by "gflsof -AW"

The first number in this log (3 in the example above) is the number of unconnected descriptors remaining.

The gflsof -AW command in the log message displays the status of open file descriptors. If the port number in the GFSD column after the colon in the display is 0, the descriptor remains unconnected. gfrmof removes the descriptor.

The gfsd process corresponding to the GPID NUMBER checked by the gflsof command can be confirmed by “gfsd: client/NUMBER” in the COMMAND field of the ps command output on the filesystem node. If the gfsd process corresponding to the GPID is found by the ps command, it will be reconnected to the gfmd soon, so please do not remove it by gfrmof.

At least one of the -d, -h, or -p options must be specified. If specified in combination, only unconnected open states that satisfy all specified conditions will be removed. Only one option of the same type may be specified at a time, nd if multiple same type options are specified, the last one specified takes effect.

Only users with the gfarmadm group privileges for the default tenant can execute the gfrmof command.

OPTIONS

-P path

Specify a pathname or a Gfarm URL to identify metadata server which will be accessed by this command. If not specified, "." is used as the default value.

-d file-descriptor

Specifies the descriptor number to be removed. Corresponds to the number in the FD column of the gflsof command output.

-h file-system-node

Specifies the name of the filesystem node to be removed. It corresponds to the part before the colon in the GFSD column of the gflsof command output.

-h global-PID

Specifies the global PID to be removed. Corresponds to the GPID field in the gflsof command output.
