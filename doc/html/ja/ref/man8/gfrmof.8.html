Name

gfrmof — gfmd に残る未接続ディスクリプタを削除する。

Synopsis

gfrmof [-P パス名] [-d ディスクリプタ番号] [-h ファイルシステムノード] [-p グローバルPID]

DESCRIPTION

未接続のまま残っている不要なファイルディスクリプタを削除します。

gfmd は、gfsd との間のファイルオープン状態を維持しています。 gfmd のフェイルオーバーの際、gfsd は gfmd へ再接続しますが、 gfsd を再起動したり、ファイルシステムノードがクラッシュしたなどの場合には、 このファイルオープン状態が残ってしまうことがあります。 このとき gfmd はディレクティブ unconnected_gfsd_watch_interval で 指定された時間間隔で、定期的に以下の警告ログを出力します。

3 write-opened descriptors remain to be unconnected in gfsd, please check them by "gflsof -AW"

このログの先頭の数字 (上の例だと 3) は、未接続のまま残っている ディスクリプタ数です。

ログメッセージにある gflsof -AW コマンドは、 オープン中のファイルディスクリプタの状態を表示します。 その表示の GFSD欄のコロンより後の部分のポート番号が 0 となっているものが、 未接続のまま残っているディスクリプタです。 gfrmof で、そのディスクリプタを消去します。

なお gflsof コマンドで調べた GPID の数字に対応する gfsd プロセスは、 ファイルシステムノード上の ps コマンド出力の COMMAND欄の「gfsd: client/数字」で確認できます。 ps コマンドで確認して GPID に対応する gfsd プロセスが存在する場合、 やがて gfmd へ再接続しますから、gfrmof による消去は行なわないでください。

gfsd と接続しているディスクリプタを指定した場合、削除は行なわれません。 単に削除操作を無視します。

-d, -h, -p オプションは 最低でもどれか一つは指定する必要があります。 また組み合わせて指定した場合には、 指定したすべての条件を満たす未接続ファイルオープン状態のみを削除します。 同種のオプションが指定できるのは1回のみであり、 複数指定した場合は最後に指定したものが有効になります。

デフォルトテナントのgfarmadmグループ権限を持つユーザのみが、 gfrmofコマンドを実行できます。

OPTIONS

-P パス名

このコマンドがアクセスするメタデータサーバを特定するための パス名または Gfarm URL を指定します。 省略した場合は、「.」を指定したのと同じ意味になります。

-d ディスクリプタ番号

削除対象となるディスクリプタ番号を指定します。 gflsof コマンド出力の FD欄の数字部分に対応します。 -d オプションは、必ず　-p オプションと ともに指定する必要があります。

-h ファイルシステムノード名

削除対象となるファイルシステムノード名を指定します。 gflsof コマンド出力の GFSD欄のコロンより手前の部分に対応します。

-h グローバルPID

削除対象となるグローバルPIDを指定します。 gflsof コマンド出力の GPID欄に対応します。
